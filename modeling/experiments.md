### 2026-10-13 — 按发售年份的标签类型演变

- **数据版本**：本机无 `data/processed/snapshots/` 快照，故直接**只读**查云库；输入明细 50,925 款游戏 / 648,006 条「游戏×标签」，交付报告的输入指纹 `049bff4b1de0`。⚠️ 指纹**每次重查都会变**——共享库被队友持续写入，同日复跑即由 `d89db9c501c0` 漂到 `049bff4b1de0`（聚合指标一致）；这正是项目要求用固定快照的原因。明细缓存落 `data/processed/tag-trends-detail.pkl`（不入 Git；本次按要求已删除，复跑重建）。**未写入 `dataset_versions`**——库对本 agent 只读，改以输入指纹记录版本。
- **口径**：年份取 `steam_appdetails.release_date`；标签源为 `game_tags` 中 `source='steamspy' AND kind='theme'`。某标签在年份 y 的占比 = 该年含该标签的游戏数 ÷ 该年有效标签游戏数；多标签游戏在每个标签上**重复计入**，故各标签占比之和大于 100%，不构成互斥分割。
- **标签归类**：`result/YJH/tag_trends.py`（本次任务后由 `modeling/tag_trends.py` 归档至此）的 `CATEGORIES` 按语义归为玩法类型 / 题材设定 / 美术与呈现 / 模式与功能 / 氛围与叙事五类，Steam 上的软件与影片单列排除；归类为人工规则，标签级统计不受其影响。
- **窗口**：出图窗口 2014–2024；增长排名主口径 2014→2020（两端覆盖率均 ≥98%）；基准年游戏数下限 30 款，避免小基数放大增幅。
- **覆盖率**：2014–2020 稳定在 98.0–99.4%；2021 起逐年下滑（93.7 / 90.4 / 87.5 / 82.3）；**2025 年仅 34.4%，已排除**。2026 年未纳入（口径 `release_date < 2026-01-01`）且尚未结束，不可与完整年份比较。
- **标签密度**：每款游戏平均标签数 2017 年触底（10.92），2020 年 15.51，2024 年 17.79。密度整体上行是多数标签占比被动上升的背景，不能一律读成「该类型变强」——这也是类目级占比全线上涨的原因。
- **增长最快（2014→2020）**：Colorful 7.0%→22.0%（+15.0pp）、Casual 35.2%→47.9%（+12.7pp）、Cute 8.4%→18.8%（+10.5pp）、Pixel Graphics 13.6%→19.3%（+5.7pp）、Exploration 9.6%→15.0%（+5.4pp）。全窗口 2014→2024 的头名另含 Singleplayer（61.1%→78.8%）与 Controller（6.2%→17.3%）。
- **缺失诊断**：SteamSpy 任务状态 99% 以上为 `ok`，但 2024 年仅 6,444/7,831 款有标签——**缺口来自数据源侧**（SteamSpy 对近年游戏不返回标签），不是本项目抓取未完成。且缺失高度非随机：2024 年无标签游戏中免费游戏占 58.0%，而有标签游戏中仅 4.1%（全样本 13.7%）；2020 年这项落差不存在（11.0% vs 11.1%）。
- **稳健性**：以「仅付费游戏」重算占比，六条变化最大的标签（3D / Indie / Great Soundtrack / Colorful / Singleplayer / Action-Adventure）走势与全样本口径**几乎完全重合**，说明 2014→2020 的趋势不是免费游戏被系统性剔除造成的假象。
- **结论**：标签占比随发售年份的变化，反映的是**现今 Steam 用户标签在不同发售年份游戏上的分布差异**，而非各年玩家的偏好变化。
- **局限（必须随结果报告）**：库中没有当年的玩家数、销量或评论历史记录，**无法据此判断某游戏在当年是否流行**，也不能用现今拥有量反推历史热度；2026 年尚未结束、其年度数量不可与完整年份直接比较；2021 年起覆盖率下降，该区间占比不可与高覆盖年份直接比较；多标签重复计入使占比之和大于 100%。
- **复现**：`uv run python result/YJH/tag_trends.py`（默认复用本地明细缓存，`--refresh` 重新只读查库）。脚本以「向上查找 `pyproject.toml`」定位项目根并自行补 `sys.path`，因此移出 `modeling/` 后仍能直接运行。
- **产物**：全部集中在 `result/YJH/`——脚本 `tag_trends.py`、图 5 张（占比折线 / 年度热力图 / 覆盖率 / 类目演变 / 稳健性对照）、报告 `tag-trends.json`（均不入 Git）；`docs/assets/tag-trends/` 目录已删。脚本顶部常量 `ASSETS` / `REPORT` 指向脚本自身目录，`DETAIL_CACHE` 单独留 `data/processed/`（18 MB 中间物，不占交付目录），重跑按此写回。类目演变图按用户要求不绘制「玩法类型」——它在各年都接近 100%，是一条无信息量的压顶线。

### 2026-10-13 — 研究首页描述性数据故事

- **数据版本**：`engagement-20261001-079598c5d7ae`，复用并验证原快照 SHA256，不重新查询云库、不训练模型。
- **统计口径**：成就数量仅纳入有效正整数；评价使用好评与差评均为有效非负整数的游戏，缺失不补零。星露谷物语为预先指定案例，要求至少100条评价、20个RAWG通关或弃坑标记。

- **呈现**：首页大数字、100格图、状态人数条形图；样本与方法默认折叠。100格图四舍五入为70格，精确比例另行显示。原六个研究专题保留。

### 2026-10-01 — 游戏级结构与参与度 baseline / Dashboard 首轮报告

- **数据版本**：`engagement-20261001-079598c5d7ae`；SHA256 `079598c5d7ae64a1be863f5d964b75ec49843802335b0ff3c34d935a730647be`。
- **固定输入**：云库只读 repeatable-read 提取的游戏级聚合快照，保存在 `data/processed/snapshots/`（不入 Git）。登记已有 `dataset_versions` 表，不执行 DDL。发售日期须早于2026年，过滤未解决映射，最终帧50,922款；抓取报告50,956款是更宽的枚举帧，不能混称同一样本。
- **目标与样本**：至少5个成就、100条SteamSpy评价。状态目标 `dropped/(beaten+dropped)` 另要求分母≥20，3,390款；RAWG时长正值取 `log1p`，11,007款；Steam好评比例14,654款。缺失状态不补零、0时长视为不可用；游戏等权。
- **特征**：元数据（年份、当前价格/免费、拥有量区间中点、评价数、固定官方类型/SteamSpy标签）；逐步加入中位完成率稀有度、成就数、P10、低于5%/1%占比、分位差。好评目标删除评价数解释特征。标签使用实测 `Rogue-like`，不自动合并其他rogue标签。
- **参数**：random_state=42；随机5折；填补和标准化在训练折内拟合；Ridge alpha=10；随机森林160棵树、max_depth=9、min_samples_leaf=15。SHAP基于最后一折留出的300款游戏，解释的是该折随机森林。未训练标准IRT/玩家能力模型。

- **A 类型对照**：稀有度与弃坑占比Spearman ρ=0.5673。稀有度增加10点对应未控制斜率+8.43个百分点，加入控制特征后+3.44个百分点；本次选取的六种类型内未控制斜率均为正，未观察到预设反转。系数受共线性影响，不作为因果效应。
- **B 尾部结构**：相对整体稀有度Ridge，弃坑目标OOF R²增加约0.0083；增益有限，不证明设计改变会改善参与度。
- **C 指标分歧**：主线联合样本中，好评比例与弃坑占比ρ=-0.3405；好评与log时长ρ=0.1424，后者成对样本3,345款。两平台不是同一批用户。
- **F 稳健性**：RAWG覆盖15,760款，覆盖/未覆盖游戏评价数中位数417/11；主线状态样本发售年份中位数2017。五组门槛（评价≥100/500/1000，状态≥10/20/50）下ρ介于0.5482–0.5673，方向为正。时长和好评模型的跨年代性能低于随机划分，不能只报告随机五折。
- **D/E 扩展**：弃坑目标文本规则Ridge R²=0.5586，标签交互Ridge R²=0.5583，相对结构模型仅+0.0009/+0.0005；未声明显著或稳定改善。文本规则未独立人工验证。Rogue-like×Deckbuilding主线样本仅28款，须谨慎解释。
- **展示**：Dashboard新增分析总览、成就结构、类型对照、口碑与参与度、模型归因、样本稳健性、内容与标签七个页面。派生报告 `data/processed/analysis-report.json` 不入Git，通过 `/api/analysis` 展示；页面含RAWG回链。

- **局限**：观察性聚合数据、状态自报与缺失、RAWG覆盖偏差、发售年代差异、当前价格不代表历史购买价、非嵌套CV的模型比较、相关特征分担SHAP。时间留出是跨发售年代检查，不是未来行为预测；全成就比例与玩家能力不可由边际完成率恢复。
