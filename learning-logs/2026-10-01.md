## 遇到什么坑

- **RAWG覆盖不等于有效样本**：状态计数缺失较多，不能补零。主线分母至少20且评价至少100后仅3,390款，明确限制结论范围。
- **标签词形导致假零匹配**：idea写Roguelike，但实测库为Rogue-like；检查固定快照标签后按实际词形重跑，不自动合并Rogue-lite等不同标签。
- **pytest误用全局解释器**：`uv run pytest`在本机落到全局pytest，找不到numpy；改用 `uv run python -m pytest`，130项通过。
- **浏览器检查脚本**：Playwright等待函数的参数需用`arg=`；Plotly生成多层SVG，等待主图须用`.first`避免严格选择器冲突。完成桌面/手机七页检查、筛选切换、历史导航和缺报告重试，零页面脚本错误、无页面横向溢出。
- **方法边界**：边际完成率不足以恢复玩家能力/完整2PL；当前用结构统计量。好评模型不把评价数分母当特征。时间留出是跨发售年代检查，不是预测未来。
