## 遇到什么坑

- 临时 OSS 签名链接会过期，且直接暴露地址可绕过面板次数限制：改为后端签名读取并转发文件，不向浏览器返回签名 URL。OSS 读取失败退还预占额度。
- scratch 镜像没有系统证书：部署时复制本机 CA 公钥证书包，保持 HTTPS 证书校验。
- 非商业许可不能表述为「完全开源」：按现有 LICENSE 与 README 写为代码公开、源码可得，并区分代码许可与第三方数据条款。
- macOS 不能直接绑定未配置的 `127.0.0.2`；改用 IPv4 与 IPv6 两种真实来源验证独立额度。现有监听地址参数使用 `[::]` 才能组成合法 IPv6 地址，验收时据此启动。
