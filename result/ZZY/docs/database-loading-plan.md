## 设计

默认 serve、baseline、check 读取仓库根 .env 中现有 POSTGRES_*，环境变量优先；支持 --env-file。配置不足明确报错，不猜 localhost，不输出连接串、密码或数据库异常原文。
独立连接使用 default_transaction_read_only=on、REPEATABLE READ、SET TRANSACTION READ ONLY，并由原 extract_rows 验证 transaction_read_only=on；只查询原已有表，不执行 DDL/DML，不导入写入入口。使用单连接、10秒连接超时、120秒语句超时，抽取结束释放。
把本次数据按内容版本保存到个人 runtime/database/snapshots；按现有规则构建或核验复用图谱，存到 runtime/database/kg。缓存只在本机产生，不写云库、不入 Git，不在数据库失败时降级旧缓存。启动审计保存本次读取时间和只读设置；复用旧内容时仍显示本次读取时间。
推荐页、算法和事实来源回查不重写。页面底部说明改为启动时只读加载；meta 增加无凭据的数据来源与读取时间。历史 AI 评价明确只对应原冻结数据，不自动套用实时数据。
--source snapshot 显式恢复旧离线入口；历史输入不改，不要求正常数据库运行时分发旧数据包。
