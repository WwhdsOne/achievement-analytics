本轮预览使用显式离线模式，复用已有冻结缓存；无数据库访问。默认只读数据库加载代码和算法保持原字节，本轮未再次对共享库执行抽取。新的数据库内容可能产生不同推荐，页面不能把历史规模或效果作为实时承诺。

浏览器故障记录、完整截图和测试输出存在本机 runtime，交付仅附验证摘要与正式截图。交付包含代码与文档，不含 .env、缓存、数据库或运行日志。未提交、推送或接入小组 Go 面板，未新增真人效果证据。

## 复核命令

在已有项目环境执行：

```powershell
node --test result/ZZY/tests/test_discovery.cjs
uv run python -X utf8 -m pytest result/ZZY/tests --basetemp=.pytest-zzy-discovery
```

`check_discovery.cjs` 需要 Node 可访问 Playwright、已安装 Edge 和已启动的离线预览服务，地址可用 DISCOVERY_URL 指定；默认8615。`check_discovery_regression.cjs` 另需同一工作区的旧交付目录和历史 replay-v2 查询报告，仅供保留这些证据的开发环境复核。
