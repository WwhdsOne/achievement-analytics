## 当前进度

更新：2026-10-17。模块重心已从成就分类工程转向**游戏级主线推进与游玩投入分析**。已完成任务1公共指标和任务2～6五个分析专题，形成固定图01～21、结果明细与汇总表，并整理综合分析报告初稿供审核。实施过程和数值结论分别集中在实验记录与分析报告，本页仅保留总览。

| 任务 | 研究问题 | 主要处理 | 主要产出 | 我完成了什么（简述） |
|---|---|---|---|---|
| 1. 主线指标 | 到达早期节点后，后续覆盖相对保留多少？ | 按剧情数组顺序选首、中、末节点，计算三个覆盖率和三个推进比 | 198款指标底表、183款完整三节点样本 | 把已有主线节点变成可比较的进度指标，支持选最多5款游戏一起看。 |
| 2. 类型比较 | 不同玩法的推进形态有何差异？ | 主类型互斥分组，多标签重叠分组，增加样本口径对照 | 类型覆盖、推进、分布及标签对照图 | 比较不同玩法的游戏在前段、后段的推进差异，并检查标签分法是否影响结论。 |
| 3. 全流程 | 同样的全程推进，是否经历不同的节点落差？ | 保留所有有效主线节点，计算相邻落差、相对位置及案例配对 | 完整曲线、相邻节点表与对比案例 | 画出完整推进过程，找出终点表现相近但落差位置不同的游戏，支持自选分组对比。 |
| 4. 时长与投入 | 绝对游玩时长和相对内容长度，哪个更贴近推进表现？ | 联结RAWG与HLTB，比较绝对时间和三种耗时比值 | 65款共同样本、相关表及参考耗时比较图 | 将平均游玩时长与主线、主线＋支线、全收集参考耗时对照，分析投入与推进的关系。 |
| 5. 口碑 | 玩家好评和媒体评分是否对应更高的主线推进？ | 四象限、三阶段相关、共同样本评分比较、多标签探索 | 183款Steam分析、140款三评分比较及案例 | 检查高评价是否也对应高推进，比较不同评分来源，并整理口碑与推进不一致的案例。 |
| 6. 同类参照 | 某款游戏相对于相似玩法，表现如何？ | 多标签Jaccard筛选参照，比较阶段差和参照分布 | 181款有效主参照结果、完整参照名单及条件对照 | 为每款游戏找相似玩法作为参照，展示其推进高于或低于同类的幅度与阶段。 |

分析全面复用WWH冻结快照中的游戏范围、既有成就分类、主线阶段、checkpoints数组顺序及玩法标签；旧LYX数据库补充HLTB参考耗时。重点案例主线节点的人工审核已由WWH完成，确认范围与来源记录见实验记录和分析报告。

此前还完成了LYX本地SQLite结构整理、前1000款数据迁移及DeepSeek整款游戏多标签分类链路；现保留五个分类模块和活跃累计CSV，旧运行历史、网页获取逻辑及一次性迁移入口已清理。旧分类进度作为带时间的历史快照保存在实验记录，不作为当前分析完成度。
