# 口碑预测最小实验

日期：2026-10-22。用户已选择“标签＋已有属性”，不补采数据、不新增依赖、不提交。

目标：预测当前 Steam 好评率，比较均值/中位数 baseline、标签 Ridge、标签＋属性 Ridge、标签＋属性 ExtraTrees。不是上市前预测。

1. 从共享库单连接、只读一致性事务提取评价≥100、2026 年前发售且有 SteamSpy 用户标签的游戏，排除未解决映射问题。原始提取保存至不入 Git 的 data/processed/wwh6/，计算 SHA256，在 dataset_versions 登记版本（唯一数据库写入）。
2. 标签取票数最高的前 20 个，二值编码；加入年份、免费状态、官方类型/功能、开发商/发行商。类别至少在训练集出现 10 款；不使用评价数、成就完成率、在线人数、评分等结果信息。价格因币种未存且未固定地区而排除。
3. 按规范化标题分组随机留出 20%；另以 2023—2025 发售游戏为测试集、2022 年及以前为训练集，剔除跨集合同标题。预处理只拟合训练数据，Ridge alpha 在训练集内分组验证；ExtraTrees 固定参数，随机种子 42。
4. 输出 MAE/RMSE/R²、相对 baseline 改善、评价门槛≥1000的子集指标、同开发商/新开发商子集指标。保存模型和逐游戏预测到不入 Git 的 data/processed/wwh6/；实验记录和报告在个人目录。
5. 真实运行后用固定快照重放，核对指标和样本分组；不新增 pytest。当前快照缺少历史时点标签、商店属性版本，跨年份仅检查跨发售年代泛化。标题分组不能保证系列/不同命名版本全隔离。
