# WWH 第 5 项实验记录

### 2026-10-13 — 全量标注完成；主线曲线口径放宽（可用样本 7 → 198）

- **数据版本**：沿用 `wwh5-2026-10-13T10:26:09.722887+00:00`（SHA256 `17a0c8e2…`），未重新取数；本地 SQLite 只读。
- **标注实况**：1000 款中 988 款完成分类、982 款完成剧情标注；成功调用 3230 次、失败 87 次（2.6%），
  累计约 11.1M token。提示词版本 `wwh5-ds-v2` → **`wwh5-ds-v3`**（见下）。
- **发现的问题**：
  1. **`gameplay` 枚举越界**：模型把 `sandbox` / `roguelike` / `shooter` / `stealth` 等 Steam 标签直接写进
     `gameplay`，导致整批 40 条成就分类作废（11 款游戏至今 0 标注）。v3 指令点名了 `sandbox/crafting/building`
     后大有改善，但 `roguelike` / `shooter` 等仍偶发（约 1.1%）。
  2. **6 款 `evidence` 为空字符串**，被校验拒绝。
  3. **主线曲线可用样本仅 7 款**——原口径要求「置信度 ≥0.8 + 统一结局 + 后续节点必经入门」，
     把「没有统一结局」与「根本没有结局」混为一谈，把「多结局但确有结局」的游戏全部丢弃。
- **口径调整（analysis.py `story_curve`，放宽三处）**：
  1. 不再要求 `unified_ending=true`；多结局取完成率**最高**的结局作分子 →「至少走到某个结局」的**下界**，绝不相加。
  2. 不再要求「后续节点必然必经入门」（该字段单独砍掉 158 款，且叠在「已判为 main+本体+非联机+置信度达标」之后，属双重门禁）。
  3. 置信度门槛 **0.8 → 0.6**（模型给出的主线置信度中位数只有 0.7，0.8 系统性砍掉一半以上）。
  4. 归一化基准由「模型指定的入门节点」改为**该游戏完成率最高的成就**（≈「玩过这款游戏的人」），
     不再依赖模型对 `start` 的判断。指标读作「走到结局的人 ÷ 玩过这款游戏的人」。
  保留的纪律：≥2 个本体公共主线节点、阶段顺序不倒退、完成率不反向上升、必须有 end 阶段节点、倒挂整条排除不重排。
- **指标（放宽后重跑 analyze，未花任何 API 额度）**：

  | 指标 | 放宽前 | 放宽后 |
  |---|---:|---:|
  | 可用主线曲线 | 7 | **198**（单一结局 120 / 多结局 78）|
  | RAWG 可配对 | 7 | **183** |
  | Spearman（分母 ≥20）| 不可用（n 太小）| **0.645** |

  Spearman 对分母阈值稳健：≥10 得 0.651（186 款）、≥20 得 0.645（183 款）、≥50 得 0.626（178 款）。
  主玩法分组均值：puzzle 0.645 > adventure 0.563 > strategy 0.361 > action 0.333 >
  platformer 0.280 > rpg 0.240 > survival 0.190 > simulation 0.145。
- **代价/局限**：指标语义由「必经路径上的通关比例」降级为「模型标出的公共主线序列上的到达比例」；
  多结局那部分只是下界。剧情顺序与节点前置关系仍是模型判断，未经人工核验。
