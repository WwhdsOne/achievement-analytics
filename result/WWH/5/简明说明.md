# 任务 5 简明说明

挑 1000 款最热门的游戏，让 AI 把每个成就分成「主线 / 支线 / 收集 / 挑战」等类别、
排出主线的剧情顺序，然后看**玩家在不同类别、不同剧情阶段的完成率差多少**，
再和 RAWG 的"通关 / 弃坑"标记对照一下。

## 数据是怎么来的

| 环节 | 用了什么 |
|---|---|
| 挑哪 1000 款 | 项目云库里评价数（好评数＋差评数）最高的前 1000 款，限 2026 年前发售、类型为"游戏" |
| 成就解锁率 | 云库里已抓好的 Steam 全局成就完成率（不用再抓） |
| 通关 / 弃坑 | 云库里已抓好的 RAWG 数据 |
| 分类和剧情顺序 | **DeepSeek 逐个判断**（这是本任务的核心工作量） |

导入之后所有东西都放在本目录的本地 SQLite（`wwh5.sqlite3`），分析不再需要联网。

## 三张图怎么看

### 1. 各成就类别的完成率（`figures/category-completion.png`）

横轴是类别（主线、支线、收集、挑战、其他），纵轴是解锁率。

**读法**：柱子越高 = 这类成就大家越容易做完。如果"主线"明显高于"收集"，
说明玩家愿意走完剧情，但不愿意满地图捡东西。

### 2. 主线推进曲线（`figures/main-story-curves.png`）

横轴从"入门"走到"结局"，纵轴是该阶段完成率 ÷ **该游戏完成率最高的成就**
（也就是"走到结局的人 ÷ 玩过这款游戏的人"）。

**读法**：曲线下降得越快，说明玩家越早流失。如果"结局"那一点接近 0，
就是"买了但没人打完"；如果一路平缓，说明这游戏黏性强。
不同颜色的线是不同玩法类型，可以比"哪类游戏更能留人到结局"。

两个口径说明：**多结局游戏**取完成率最高的那个结局，所以那个数是"至少走到某个结局"的
**下界**（图上标题会写"单一结局 120 / 多结局 78"分开计数）；这个比例**不是弃坑率**。

### 3. Steam 与 RAWG 完成口径对比（`figures/rawg-comparison.png`）

一张散点图：每个点是一款游戏，横轴是 Steam 算的、纵轴是 RAWG 算的。

**读法**：点越贴近对角线，说明两个平台的口径越一致；完全散开说明两边的
"通关"定义差很多。这里主要看**趋势和排序是否一致**（Spearman 相关系数），
不是看谁更准。

## 想自己跑出结果

在项目根目录依次执行：

```bash
# ① 从云库导入前 1000 款（只读，不改云库）
uv run python result/WWH/5/run.py export

# ② 先看看要调用多少次模型（不花钱）
uv run python result/WWH/5/run.py label --dry-run

# ③ 先用 3 次真实请求验证 key 配好了没
uv run python result/WWH/5/run.py label --max-requests 3

# ④ 正式标注（会持续花钱，中断了重跑同一条命令即可续做；默认 4 款游戏并行，想串行加 --workers 1）
uv run python result/WWH/5/run.py label

# ⑤ 出图和报告
uv run python result/WWH/5/run.py analyze
```

密钥写在同目录的 `.env`（照 `.env.example` 填 `DEEPSEEK_API_KEY`），**不要提交进 Git**。
