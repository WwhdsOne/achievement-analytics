# WWH 个人工作区

用户要求：WWH 的代码、配置、schema、测试、文档、实验记录和学习日志全部放在 `result/WWH/` 内，各任务放到对应编号目录。

- 第 5 项位于 `5/`；第 6 项开展时放到 `6/`。不要将个人模块或测试写进公共 `modeling/`、`cleaning/`、`crawler/`、`tests/` 等目录。
- 每个任务使用自己的入口、配置模板、SQLite schema、pytest 配置及 `.gitignore`。个人密钥放各任务的 `.env`，不写到项目根配置。
- 可仅读共享文档与已有 PostgreSQL 连接配置、使用项目已有 uv 依赖；不修改共享采集库或公共项目配置。
- 实验记录与中文学习日志也写在任务目录内；运行产物、测试临时文件与缓存留在个人目录。
- 保持原始数据、模型调用明细和密钥的 Git 忽略规则。仍须等用户明确指示后才 commit、amend 或 push。
