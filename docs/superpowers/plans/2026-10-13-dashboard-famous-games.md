# 知名游戏数据展示

用户要求：dashboard 删除预测、随机森林等内容，只保留易读、有趣的数据，优先知名游戏。

实现范围：
- 展示12款预先选取的知名游戏，来自同一固定快照，中文名为常用名；缺失指标独立处理，不拿缺失当零。
- 用四个页面替代原研究专题：成就数量对比、名作口碑、通关与放下、热门之外。原生条形图及100格图，保留游戏详情跳转、键盘操作和移动布局。
- dashboard API只返回故事及必要的版本信息；移除旧专题导航、旧代码、绘图库路由和下载中的技术报告内容。旧地址回到展示首页。
- 故事命令支持直接从已有快照创建报告，无需先运行完整实验。独立研究脚本不属于此次 dashboard 删除范围。
- 测试数据分母/缺失、API只返回展示内容、切换游戏、旧地址、空样本/旧报告、桌面与手机。
- 沿用用户已授权的提交与推送流程，仅暂存本轮变更，保留原工作区其他修改。

验证完成：工作区138项单测通过；独立导出的暂存版本129项通过。两份版本都通过桌面/手机四页检查（共8种布局），无横向溢出或脚本错误；已核对截图、切换游戏/排序、旧路由、空数据及缺报告重试。dashboard源码已无预测/随机森林/SHAP等内容。
