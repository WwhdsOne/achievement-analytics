# 游戏探索实施计划

目标：合并游戏数据故事与 AppID 查询，支持搜索、趣味发现、详情与两款游戏对比。用户已确认开始实施；直接在 main 工作，不提交、不部署、不改 schema。

技术：Go 只读 API + embed 原生 JavaScript/CSS，共用现有连接池。探索直接读云库，不依赖建模报告。

- [x] 新增 `dashboard/explore.go`：参数化名称搜索、评价数量榜、成就数量榜、免费游戏、同开发商作品、玩家标签和同名成就。查询设超时，发现列表缓存五分钟。

- [x] 合并导航；搜索支持 AppID、名称、Steam 商店链接。复用成就明细和逐源状态；来源状态折叠，移除完成曲线和通关/弃坑展示。旧 hash 跳转到新入口。
