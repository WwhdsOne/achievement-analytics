# 研究首页数据故事实施计划

**目标：** 将已确认的三个数据故事放到研究首页：成就数量、评价长尾、星露谷物语的好评与状态标记。数字由固定快照生成，技术内容放到展开区。

**实现：** `modeling/regression/stories.py` 负责纯统计与已有报告的同版本更新；常规分析生成器也输出 stories。`dashboard/analysis.js` 与 CSS 负责大数字、100格图、状态人数条形图。既有专题保留，入口收进“深入研究”。不新增依赖、不读写云库、不更改 schema。
