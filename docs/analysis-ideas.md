## 1. 课程主线（必须做）

### Q1：成就难度结构（支撑）

- **当前可做的 baseline**：全局完成率分位数、低完成率成就占比、分布形状，以及 `-logit(p)` 稀有度指标；p 为 0–1 比例，端点处理规则须记录。
- **产出**：每款游戏的成就完成率结构画像，作为 Q2 的解释特征。低完成率同时反映挑战、流程位置、可选内容和投入，不等同于纯技术难度。
- **IRT 可行性待评审**：原计划的 Rasch 1PL → 2PL 依赖玩家×成就联合响应。当前只有逐成就边际完成率，不能据此识别玩家能力与完整 2PL 参数；不从完成率独立生成伪玩家矩阵冒充观测。参见 [mirt 官方输入说明](https://philchalmers.github.io/mirt/reference/mirt.html)。本次不新增玩家采集，也不将标准 IRT 拟合列为可直接执行的任务。
- **口径注意**：percent 会漂移 → 先登记并绑定固定数据版本；仅登记版本号不足以冻结会被覆盖的源表，还须明确快照或固定提取方式。

### Q2：玩家偏好归因（核心）

- **方法**：参与度（RAWG 平均时长 / 通关占比 / 弃坑占比 / SteamSpy 好评率）~ 特征（类型、标签、价格、热度、难度结构）回归 + **SHAP 归因**
- **产出**：什么特征的游戏被玩得更久、更少弃坑，SHAP 摘要图
- **口径注意**：SHAP 是模型归因不是因果；RAWG 样本限 15,770 款且偏主流（`docs/data-report.md` §6.1）
- **baseline 与评估**：各因变量分别建模，先线性回归，再考虑树模型；报告交叉验证 R² / RMSE，并按年份或类型检验稳健性。好评率是口碑指标，时长和状态占比是参与度代理，不先合成总分。
- **避免机械关联**：若因变量来自成就完成率，不用同组完成率的中位数、P10 等去证明「难度解释参与度」；完成率结构优先预测独立来源的 RAWG 指标。预测 CCU/owners 时，同样避免把该比值的组成量直接作为解释特征。

## 2. 数据故事（展示向，按「效果/成本」排序）

### ① 难度 × 弃坑四象限图 ⭐ 首推

```
x = 成就完成率结构代理   y = 通关或弃坑标记者中的弃坑占比
y = RAWG dropped / (beaten + dropped)，分母必须 > 0
色 = 类型   大小 = 拥有量区间中点
```

四象限可用于观察「低完成率但少弃坑标记」等组合，FromSoftware、空洞骑士、只狼是待核验的标注候选，象限归属由结果决定。
**成本**：半天。**已有数据**：相关字段已有，实际可用样本须检查分母与缺失。**产出**：一张报告概览图。
**口径注意**：本比例与 `game_engagement.dropped_ratio` 的分母不同，不能混称；该视图使用 owned + beaten + dropped + playing，owned 本身不能证明已经游玩。按状态标记分母设置样本门槛并展示不确定性，不能用评分人数替代状态人数。不同分母可作敏感性对照。

### ② 「魂like 现象」专题 ⭐ 已有结论雏形

用 `Souls-like` 标签（**774 款**）对比全量：**已实测**——

```
Souls-like 成就完成率中位数  14.3%   ← 完成率更低，不代表难度翻倍
全部游戏                     27.4%
```

进一步拆：魂like 的时长、好评率、通关/弃坑标记占比 vs 普通动作游戏，并控制年份和热度。检验低完成率与参与度是否相关，不预设「越难越留人」。**成本**：2~3 小时。
同法可复制的专题：`Cozy`（585 款，反方向）、`Difficult`（4,636 款）、`Metroidvania`（927 款）、`Female Protagonist`（4,369 款）。

### ③ 成就完成率结构示例（不做聚类）

按完成率分位数与低完成率占比选取代表游戏，展示以下待核验结构：

- 多数完成率较高，尾部少数成就完成率极低
- 排序后的完成率存在明显落差
- 排序后的完成率平滑下降
- 高完成率成就占比较大

每种结构贴代表游戏，服务于 Q1 特征说明与下文 B 的检验。**成本**：半天至一天。**口径注意**：排序曲线不是玩家推进时间线，不能识别具体弃坑关卡。分群/聚类已裁剪，不列入执行范围；观察性比较不能回答成就设计的因果效果。

### ④ 标签年代剧

`release_date × game_tags`：Roguelike / Deckbuilder / Cozy / Bullet Heaven 等标签的历年兴起，「独立游戏审美变迁」面积图。**成本**：半天。
注意：SteamSpy 的标签名以实测为准（如没有 `Survivors-like`，需先 `SELECT tag, count(*) GROUP BY tag` 排查）。

### ⑤ 「稀有成就名人堂」

从 197 万条成就里筛 `percent < 0.5%`（现在有 **90,593 条 <1%** 的成就），列出：成就展示名（映射的成果）+ 所属游戏 + 完成率排名。一屏趣味表格。**成本**：1 小时。低完成率可能来自停服、多人条件、刷取或不可达成内容，不能直接排名技术难度。

### ⑥ 被低估的游戏推荐（收尾彩蛋）

`rating ≥ 4.0 且 playtime ≥ 20h 且 owners 区间 ≤ 10万` → 「我们的系统找出的 20 款冷门神作」，每款附 SHAP 解释为什么上榜。**效果**：展示模型有实用价值。

## 3A. 补充方向（数据科学课程向，待审阅）

优先推荐 A、B、C：它们直接连接 Q2，分别检验混杂、结构差异与指标含义。D、E 属于扩展特征工程，F 属于主线稳健性检查。以下均为假设，不是已有发现。

### A. 「越难越受欢迎」是否由类型差异造成？【优先】

- **问题**：全量关系与动作、解谜、视觉小说等类型内部的关系是否同向？是否出现辛普森悖论？
- **数据**：成就完成率结构、genres/标签、年份、价格、热度，以及 RAWG 状态计数或时长。
- **方法**：先画整体与类型内趋势，再用线性回归逐步加入控制变量，比较系数与交叉验证表现；不为得到反转而挑选分组。
- **产出**：整体/类型内趋势图、控制前后系数对照，以及 Souls-like 专题的适用范围。
- **成本与口径**：约半天至一天；RAWG 有效样本按目标分别统计，多标签游戏的比较组定义须明确。控制变量后的关联仍非因果。

### B. 整体低完成率与尾部极低完成率，是否对应不同参与度？【优先】

- **问题**：多数成就都稀有，与多数较常见但少数极稀有的游戏，参与度是否不同？
- **数据**：中位完成率、P10、低于 1%/5% 的占比、分位数差、成就总数，结合 RAWG 指标。
- **方法**：先单特征与线性回归 baseline，再比较加入尾部特征前后的交叉验证 R²/RMSE；必要时用预先规定的分段关系检验非线性。成就数量不同的游戏用分位数/占比比较，不直接比较不同长度向量。
- **产出**：结构示例图、结构特征的增量解释力，检验「难在哪里」是否比单一难度数更有用。
- **成本与口径**：约一天；不能从分布直接认定极稀有成就是可选挑战，可抽样用展示名与描述核验。Q2 目标使用独立来源指标。

### C. 「觉得好」与「愿意玩下去」是否一致？【优先】

- **问题**：哪些游戏口碑高却少有通关标记，哪些口碑一般却有较长时长？这种分歧是否集中于某些类型？
- **数据**：Steam 好评/差评计数、RAWG 时长、通关与弃坑状态计数、类型与年份。
- **方法**：分别分析指标相关性与类型内关系，展示分歧样本；好评比例和状态比例分别按自己的分母筛选，门槛变化作敏感性检查。
- **产出**：口碑×参与度散点图、代表游戏表，以及选择 Q2 因变量的依据。
- **成本与口径**：约半天；长时长也可能来自重复刷取，低通关占比可能来自开放式玩法。RAWG 与 Steam 不是同一批用户，不能推断个体「嘴上喜欢却不玩」。

### D. 成就内容是否比成就数量更有解释力？【扩展】

- **问题**：剧情推进、收集、重复刷取、技术挑战、多人协作等内容占比，能否补充数量和完成率结构？
- **数据**：`achievements.display_name`、`description`、游戏级目标及现有控制特征。
- **方法**：先制定可多标签的分类规则，人工标注一小批，再做关键词 baseline；在独立核验样本上报告分类表现。汇总内容占比后，与原 Q2 模型使用相同数据划分比较。
- **产出**：文本分类规则、核验误差、内容特征带来的增量预测表现。
- **成本与口径**：约一至两天；多语言、幽默命名和缺失描述增加误差，缺失项单独标记，不强行分类。不要把完成率阈值当作内容类别的人工真值。

### E. 标签组合是否有额外解释力？【扩展】

- **问题**：Roguelike 与 Deckbuilder、Action 等搭配时，参与度关系是否不同？
- **数据**：SteamSpy 题材标签、RAWG 目标、年份/价格/热度控制特征。
- **方法**：预先选少量样本充分的组合，对比只有主效应的线性回归与加入交互项的模型；以交叉验证表现判断增益，树模型和 SHAP 放在 baseline 之后。
- **产出**：组合对照图、交互项与模型增益表，进一步解释「什么组合有特点」。
- **成本与口径**：约一天；低频组合容易出现偶然结果，须报告样本数并控制多重比较。官方 genre 与玩家标签含义不同，不无条件混合。

### F. 结论有多依赖 RAWG 的主流样本？【稳健性必做】

- **问题**：RAWG 覆盖游戏与全量游戏有什么系统差异？Q2 特征排序是否随评价数门槛改变？
- **数据**：全量可得的年份、价格、标签、热度、成就结构，RAWG 覆盖标记与各目标的有效性标记。
- **方法**：先比较覆盖/未覆盖样本的特征分布；再在不同评价数与状态人数门槛下重复 baseline，样本充分时比较 SHAP 排序。区分未安排 RAWG 抓取、匹配失败、目标字段不可用。
- **产出**：覆盖偏差图、门槛敏感性表，说明主线结论适用于什么样的游戏。
- **成本与口径**：约半天至一天；成功匹配不等于所有目标可用，15,770 款是覆盖上限。敏感性分析不能恢复未覆盖游戏的真实行为。

## 5. 口径红线（任何分析不得越界）

1. **只有游戏级聚合，没有个体玩家**——「偏好」是从人群完成率/弃坑率反推，措辞注意
2. **RAWG 样本只覆盖 30.9% 全量且偏主流**——凡用 RAWG 字段的分析都要声明样本范围（见 `docs/data-report.md` §6.1）
3. **SHAP = 模型归因，不是因果**
4. **percent 漂移**——所有分析绑定 `dataset_versions` 登记的版本（**当前为空，建模前必须先登记**）
5. **3 条未解决映射**（appid 627690 / 767490 / 1851090）——分析时过滤
6. **RAWG 回链**——最终展示页必须加 RAWG 出处链接（使用条款要求）
7. **边际完成率不等于联合响应**——不能估计完整玩家能力/2PL 参数；最稀有成就完成率只是全成就比例的上界，不能当作实际全成就比例
8. **比例名称与分母绑定**——RAWG 自报状态占比不等同于全体 Steam 玩家通关/弃坑率；缺失不能未经核验直接视为 0，评分人数不能替代状态人数
9. **完成率曲线不是时间线**——成就排列或按完成率排序不能证明先后解锁顺序、具体弃坑关卡或生存概率；不新增弃坑生存分析、跨游戏迁移、玩家分群或 PSN 数据
10. **口碑、参与度与活跃度分别解释**——好评不是时长，CCU 快照不是留存率；避免用目标组成量或同组统计量构造看似很强的解释

## 6. 建议的推进顺序

```
当前：首轮分析与dashboard实施已完成，检查结果后再确定后续实验
审阅通过后：固定数据版本 → 过滤未解决映射 → 核验目标/分母/有效样本
主线：Q1 完成率结构 baseline → C 指标分歧 → A 类型内外对照 + B 结构拆解
      → Q2 线性回归 → 树模型与 SHAP（视 baseline 结果）→ F 稳健性检查
展示：① 四象限 + ② Souls-like 专题；③结构示例、④⑤⑥按时间取舍
扩展：D 成就内容 / E 标签交互，优先级低于主线与稳健性
```

**建议叙事**：成就完成率结构是什么 → 它与参与度有什么关联 → 这种关联是否依赖类型、指标与样本范围。以可检验问题串联展示，不预设「难度让玩家更愿意玩」的结论。
